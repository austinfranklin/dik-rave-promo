# Algorave poster wall

Upload every file in this folder to the root of your GitHub Pages repository.

## One thing to change before you share the link

Social previews (LinkedIn, Facebook, Slack, X) need the page's full web address.
Open `index.html`, find this text (every occurrence, all near the top):

    https://YOUR-USERNAME.github.io/algorave/

and replace all of them with your real GitHub Pages address, for example
`https://anna-svensson.github.io/algorave/`. Keep the slash at the end.

## Files

- `index.html`: the whole site (all 40 posters are inside it)
- `og-image.jpg`: the 1200×630 image shown in link previews
- `apple-touch-icon.png`, `favicon-32.png`: home-screen and browser-tab icons

## Checking the LinkedIn preview

After the site is live, paste the address into LinkedIn Post Inspector
(linkedin.com/post-inspector). It shows the preview and refreshes LinkedIn's
cached copy, which is useful after any later change.
